## 1. The C memory model, step 1 of the old validation plan

The Lean core is `grammatik/Grammatik/CBackend/Semantik/CSpeicher.lean`. It supersedes the memory
of `CSemantik.lean` and carries that lane's results over as a refinement.

**The decision in five lines**

1. Block-offset memory in the style of CompCert, restricted to what the emitter creates: one block
   per C object; a pointer is a block plus an offset; arithmetic moves the offset, never the block
   (that is the whole provenance rule).
2. Typed cells, not bytes: each block has a layout from the emitter's own declarations (`count`
   records of scalar fields at byte offsets). A load or store must hit a cell of exactly its type
   (C11 effective type). Enough because the emitter never reinterprets ordinary memory.
3. UB means stuck: every access checks block, lifetime, kind, bounds and cell type; the inventory
   is complete for the check (`accOk_iff`).
4. A separate observation trace: volatile device accesses, atomic operations with their order and
   port I/O append events; a volatile read takes its value from an environment oracle.
5. No `malloc`, no bytes, no unions, no weak memory: each named in section 7 with the extension
   that would lift it.

### 1a. The C objects the emitter creates (census of 2026-09-13, 227 emitting units, 15,199 lines)

The counts are that day's, on a binary that predated the arena storage; kinds, not counts, are the
lasting content. Re-measure with `instrumente/zaehle-c-formen.py` and `gabbro emit` over the corpus.

| C object (emitted shape) | block in the model |
|---|---|
| table type `typedef struct { T_slot slots[N]; } T;`, storage `static T T_speicher;`, `T *restrict t` parameter | `CBlk.tab t` with layout `RecLay` (count N) |
| file-scope scalar / array / struct | `CBlk.glob g`, plain, 1 or N cells, or record |
| file-scope `_Atomic T g;`, per-core `_Atomic T g_zellen[NKERNE]` | `CBlk.glob g`, atomic |
| `static const … section(".rodata")` | `CBlk.ro c` |
| arena storage `static A_arena A_arena_speicher;` (`buf[hi]`, `used`) | `CBlk.arena a` |
| stack scalars (no address taken) | environment |
| stack structs/arrays/address-taken locals, CAS expected locals `&_cxN` | environment or `CBlk.stk fr x` |
| device handle `typedef struct { volatile uint8_t *basis; } D;` from `(volatile uint8_t *)(uintptr_t)BASE` | record with one `ptr` cell; `devHandle` -> `CBlk.dev d` |
| byte view `{ uint8_t *bytes; uint32_t len; }` | record `{ptr, u32}` into a byte block |
| foreign function returning `T *`, traversal callbacks | `CBlk.ext n` (foreign provenance) |
| const function pointers | not memory (a named function) |
| null object pointer `(Platz *)(uintptr_t)0` | stuck (finding 1, section 6) |

There is no heap in the emitted C: no `malloc`, `free`, `calloc`, `realloc` or `alloca`; arenas are
static arrays. The block kinds `tab`, `glob`, `arena`, `ro`, `stk`, `dev`, `ext` cover every row.

### 1b. Pointer shapes

`t->slots[i].f` (table block, `i*sizeof(T_slot) + offsetof(f)`); pointer arithmetic (598 sites, all
`base + constant` or `base + i*stride + constant` on a byte view, a device window or a byte helper,
so none leaves its block by construction: `ptrAdd` progress under the layout bound); index on a
pointer (192, in byte helpers and tree descents); dereference (227, of which 153 volatile register
cells and 42 mis-counted function-pointer declarators); address-of (199); pointer casts (163, of
which 153 are `volatile uint8_t *` to `volatile uintN_t *` on a device base, 9 are
`(volatile uint8_t *)(uintptr_t)`, 1 is the null constant, **none on ordinary memory**).

**Why typed cells suffice:** every cast either targets a device window (observations, not memory)
or is the null constant (stuck). Byte views read `uint8_t` cells only; endianness is composed in C
arithmetic, never by reinterpreting a buffer. If the emitter ever reads a `uint32_t` through a
`uint8_t` buffer the model needs CompCert byte fragments, and the census should ratchet that row.

### 1c. Volatile and atomic accesses

Volatile register cells `*(volatile uintN_t *)(base + off)` are emitted at widths 8/16/32/64.
Atomics are emitted only through the explicit forms `atomic_load_explicit`,
`atomic_store_explicit`, `atomic_compare_exchange_{weak,strong}_explicit`, with
`memory_order_{relaxed,acquire,release,seq_cst}`; no `atomic_exchange`, `atomic_fetch_*` or
`atomic_thread_fence` in the corpus of that census. Inline assembly appears for port I/O, `mfence`,
`sfence`, `invlpg` and the syscall stub.

**Every atomic access goes through an explicit `atomic_*_explicit` call; none is a plain access to an
`_Atomic` object.** So the model makes a plain access to an atomic block stuck
(`plain_on_atomic_stuck`). This restricts the subset; it is not a C rule. The checker and the emitter
cite this paragraph as "the C model (`C-SPEICHERMODELL.md` section 1c)": a bare store to an atomic
is stuck here, and refused by the checker.

## 2. The model (`CSpeicher.lean`)

```
CTy   := int (sgn : Bool) (w : CWidth) | ptr
CBlk  := tab t | glob g | arena a | ro c | stk fr x | dev d | ext n
CPtr  := { blk : CBlk, off : Int }
CVal  := int v | ptr p | undef
RecLay := { count, nf, fty, off, ssize }          -- count records of nf fields
BKind := plain | readonly | atomic | mmio
CSt   := { mem, live, obs : List CObs }
CObs  := vrd | vwr | ard | awr | acas | pin | pout
```

**The access check** (`accOk L st p tau md`): the block exists and is alive, its kind admits the mode,
the offset is non-negative, and `lay.cell off = some tau`. Padding, the middle of a field, one past the
end and a type mismatch all give `none`.

**The UB inventory** (each item stuck, the check complete by `accOk_iff`): `AccUB.noBlock`, `.dead`
(C11 6.2.4p2), `.mode` (plain access to `_Atomic`/MMIO, store to `const`), `.negOff`/`.pastEnd`
(6.5.6p8), `.noCell` (effective type, misalignment), `LoadUB.uninit` (6.7.9p10), `StoreUB.range` (value
outside the declared type), `PtrUB.below`/`.above`, `OrdUB.load`/`.store`/`.casFail` (7.17.7).

**Operations:** `bLoad`, `bStore`; `ptrAdd` (`ptrAdd_blk`, `ptrAdd_add`); `addrOf`, `enterFrame`,
`leaveFrame`; `vLoad`, `vStore` (observation, oracle `DevOrc`); `aLoad`, `aStore`, `aCas`; `devHandle`
(an integer becomes a device pointer only at the declared base); `portOf`, `portIn`, `portOut`.

**Layouts.** `natLay` is the natural-alignment LP64 rule (x86-64 SysV; AAPCS64 states the same sizes
and alignments for the integer and pointer types the emitter produces, a claim about the ABI texts that
was not measured). `RecLay.wf` is a `Bool`, so a certificate's layout is checked by `decide`; from it
follow `RecLay.pos_inj` and `RecLay.cell_pos`.

## 3. Refinement of the first C semantics (`CSpeicher.lean` section 11)

The five base forms keep their syntax (`CExpr`, `CStmt`) and get a second semantics `bEval`/`bExec`.
The old memory is a projection (`projMem`), and the refinement runs both ways, stuck for stuck:

```
bEval_refines : (forall t, (TL t).wf) -> e.fieldsOk TL -> Good TL st -> bEval TL e st rho = aEval e (projMem TL st) rho (geomOf TL)
bExec_refines : ... -> RelOut TL (bExec TL s st rho fuel) (cExec s (projMem TL st) rho (geomOf TL) fuel)
```

It holds for every statement of the five forms, loops included (`forRun_refines`).
`cCorr_assignSlot_blk` is derived from `cCorr_assignSlot`.

## 4. Correspondence to Gabbro's memory (section 12)

`EmitLay D` is the emitter's layout of a declaration, given as data with the facts a certificate carries
(table -> block number and well-formed record layout; field -> position with a fitting C type; global ->
block number, one cell, `_Atomic` exactly when `atomic`). The relation `corrW EL sigma st` says every
non-ghost table cell and global holds the encoding (`encW`) of the Gabbro value. The theorems
`corr_schreibSlot`, `corr_leseSlot`, `corr_schreibGlob`, `corr_leseGlob` and the atomic variants say a
Gabbro store or read has a matching emitted store/load that cannot get stuck (`encW_fits`,
`RecLay.cell_pos`). Witnesses: `refKonto_zeuge` on `beispiele/104-referenz.gab`, `geraet_zeuge` (device
window), `ausgabe_zeuge` (out-parameter).

## 5. The C forms against the model

Memory role per emitted form: cells (`static`, `struct`, arrays, field access, `sizeof`, `[]`), pointer
(`T*`, `->`, pointer arithmetic, index on a pointer, `&`, `*`, casts, frames), trace (`volatile`,
`memory_order_*`, port I/O) and "none" (preprocessor, control flow, `goto`, `typedef`, `const`,
`restrict`). Not expressed by the core: `union` definitions (tagged unions), `float`/`double` (a
one-constructor extension, `CTy.fl`), foreign `void*` (a named assumption), opaque `asm` bodies
(`mfence`, `sfence`, `invlpg`, syscall), and `register` syscall variables. Aggregate values (by-value
struct locals, compound literals, struct returns) are a gap in `CEnv`, not a form. The per-form state
(lemma / assumption / uncovered) is `pruefe-cformen.py`'s register.

## 6. Findings that stand

1. **A null pointer was dereferenced in the emitted C** (`beispiele/38`): `(T *)(uintptr_t)0` is a null
   pointer constant (C11 6.3.2.3p3), so no emitter spelling can cure it. Fixed at the checker: `N260`
   refuses an immutable pointer starting at `0`. Remainder: a `static mut` pointer starting at `0`
   still lowers to a null spelling (the kernel NULL-init idiom; flow, not a declaration).
2. The 153 pointer casts `volatile uint8_t *` -> `volatile uintN_t *` are harmless for strict aliasing
   (they target MMIO, not memory); the old plan sentence "no cast between pointer types" needed that.
3. The census over-counts two forms (42 of 227 dereferences are function-pointer declarators, 2 of 598
   pointer-arithmetic sites are integer arithmetic): lexer approximations, the class is right.

## 8. C names: what C has already taken (`cnamen.rs`, `N041`)

The generator writes the Gabbro name into C **unchanged**: no module prefix, no escape form, `emit.rs`
has no `c_name` function. So every name C owns is a name a lowering cannot use, and the checker says so
(`N041`), not `cc` three tools later. The table in `crates/gabbro-check/src/cnamen.rs` is a measurement
of 2026-08-31 (GCC, `LC_ALL=C`, `-std=c11 -O0 -Wall -Wextra -Werror`), over the set a Gabbro program can
write and the emitter really produces:

| Class | raw | Gabbro-reserved | reachable |
|---|---:|---:|---:|
| C11 keywords (C11 6.4.1) | 44 | 7 | **37** |
| names of the four headers the generator includes (`<stdint.h> <stdbool.h> <stdatomic.h> <math.h>`) | 370 | 4 | **366** |
| GCC built-in functions (work with no `#include`) | 326 | 1 | **325** (155 not already in the header class) |
| union | | | **558** |

The seven unreachable keywords (`const else extern if return sizeof static`) already fall at `P002`.
The built-in class is the unsettling one (it caught fragment `F05`: `extern fn exit()` conflicts with the
built-in `void exit(int)`), measured one file per candidate with no header at all.

Which FORM breaks on which name (`exit abort malloc free memcpy printf` break `extern fn`, `pub fn`,
`impl fn`; `bool true NAN` break every form; `uint64_t` breaks everything but `let` and parameters;
`INFINITY` all but types and parameters) is the table the rule is built from. Two measured findings:
`read` is **not** a C-name problem (POSIX, no header of the four), and C11 7.1.3's reserved prefixes
(`_X`, `__x`) do not break (no measured need, so no rule; the 883 underscore names the headers define
are one libc's spelling, not C's). Cost of the rule over 418 files and 743 top-level names: exactly one
hit, `exit` in `messung/fragmente/F05.gab`.

**Not built, with the reason:** no rule against a leading underscore; no renaming in the emitter (a
silent `gabbro_exit` moves the explanation into output nobody reads); no exception for `extern fn` (no
corpus file calls a C library function, and `F05`'s `exit()` means process abort). Names the GENERATOR
forms (suffixes such as `Eintrag_gueltig`, `Kappe_NONE`) are the other half: `erzeugernamen.rs`.
Re-measure: the commands are in the `cnamen.rs` module head.

## 9. The generator sweep: the emitter's promise, measured (2026-09-02)

The property: for an input the checker **accepts**, `gabbro emit` must **lower it** (exit 0, and the C
compiles under `cc -std=c11 -O0 -Wall -Wextra -Werror -c`) or **refuse by name** (`C001` with a note).
The sweep instrument `fuzze-erzeuger.py` (and `fuzze-grenzen.py`, its checker-side sibling) is no longer
in `instrumente/`; the results below are the dated record, git history has the tool.

First full run (5,889 cases over 64 declaration forms, tree `41782b0`): 3,517 accepted by the checker;
3,039 lowered, 478 refused by name; **273 lowered units did not compile** and 69 more lost the swept
number (oracle); no third answer (shape 1: 0), debug and release byte-identical (shape 4: 0).

| Defect | What | Probe |
|---|---|---|
| D1 | a `walk` descends through a `reserved` field (no accessor is written) | `gift/641` |
| D2 | a `forever` loop as the whole body of a function that answers (`-Wreturn-type`; 65 of 65 rungs) | `gift/642` |
| D3 | an integer literal without `u` where the value exceeds `int`/`long` (54 cases, nine forms) | `gift/643` (not present in the tree today) |
| D4 | `embeds ... scale 2^64` written as a literal wider than any C integer | `gift/644` |
| D5 | an array length past C's maximum object size | `gift/645` |
| D6 | a `section` name copied into C with nothing escaped (empty, doubled quote, trailing backslash, NUL) | `gift/646` |
| oracle | `entry` vector / IST / nested bound above what the emitter can write (69 cases) | `dokumente/FRAGMENTE.md` 7.7 item 3 (the `konst_zahl` shape found mechanically) |

Lessons that outlived the instrument: a baseline is only good against the question it was asked (the
checker-side sweep's two `walk` templates carried D1 at their baseline); a gate over a corpus measures
the corpus (`pruefe-emission.sh` was green while no unit put a `forever` in an answering function); a
probe compiled with `-fsyntax-only` never assembles, so half of D6 was invisible to the poison harness.

**The class behind the zeros: a literal that becomes a size, count, stride, scale or divisor, where
zero is meaningless.** Eleven positions measured, two escaped:

* `table T count 0` was a FILTER, not a missing rule: `umgebung.rs::sammle_kapazitaeten` dropped a zero
  capacity (`.filter(|n| *n > 0)`), so `M103` got no bound, and the emitter wrote `T_slot slots[0]` and
  an out-of-bounds read. **Repaired in both halves with no new code**: the capacity map records zero
  (`M103` refuses every index), and `emit.rs` refuses the declaration by name. Probe `gift/647`, test
  `rechenwerk.rs::die_leere_tabelle_hat_eine_schranke_und_kein_erzeugnis`. *A zero dropped is a zero
  unchecked.*
* `embeds ... scale 0` (every address zero) stays booked, not refused: its argument differs from `N010`'s
  (an empty domain holds vacuously; a zero scale makes statements WRONG), and one code over both would
  make every probe on it ambiguous. Characterisation test
  `rechenwerk.rs::ein_massstab_von_null_liest_nichts_und_niemand_sagt_es` pins today's `* 0u` and goes
  red the day the scale is refused.
* Already covered: `bank ... stride 0` (`N010`), `accumulates ... per cpu 0` (`N014`), division by a
  literal or const zero (`M102`), zero-length arrays and walks (`C001`), `bank ... count 0` (`M103` at
  every use), `aligned(p, 0)` (`C001` everywhere, so the modulo by zero exists in no artefact).

**Not measured by the sweep:** the C is compiled, not run (that is `pruefe-emission.sh`); 1,664 of 3,046
lowered cases had no oracle; the checker's own answer is taken as given; one slot at a time.
