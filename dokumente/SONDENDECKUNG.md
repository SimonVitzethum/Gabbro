# `A_p` — the probe quota, and the floor it does not reach

**This file retires `K100`'s gate `A = 19`.** It says what replaces it, what the replacement
measures, what the tree measures against it **today** — and it is RED, on purpose, because a
bound the tree already meets is a decoration and not a gate.

    ./instrumente/pruefe-sondendeckung.py

---

## Why `A = 19` is retired

`dokumente/PLAN.md` fixes the target and its arithmetic in one sentence: *„`gabbro annahmen`
stand beim Schreiben dieses Absatzes bei **14**; nach K100 muss dort **19** stehen"* —
**19 = 14 + the five rebookings of `K100.2`**. `DONE.md` records the day it was hit.

**So 19 was never a bar over the trust surface. It was a prediction of a delta, and it came
true on 2026-08-17.** What has happened since is that its measurand grew: 44 names over 40
distinct sentences, four of them generated by the checker and declared in no `.gab` at all.
`messung/AXIOMSCHICHT.md` §8.4 measured that and drew the conclusion this file acts on:

> **A target that a new example file can miss is pointed the wrong way.** Adding
> `beispiele/65-port-space.gab` raised `A` by two, and nothing about the trust surface got
> worse — the file made an existing machine dependency EXPLICIT, which is the movement the
> axiom layer exists for.

*Under `A = 19` as a gate, the cheapest way to pass is to write fewer programs, and the second
cheapest is to write `unfalsifiable` twenty-five times.* The second exit is latched by
`dokumente/UNFALSIFIZIERBAR.md`. **This file latches the first, and it latches the state
between them.**

---

## The three states, and the one that had no guardian

An assumption is in exactly one of three states:

| state | today | who watches it |
|---|---:|---|
| **unfalsifiable**, under a criterion | 6 clauses / 1 admitted | `pruefe-unfalsifizierbar.py` — a ratchet DOWN |
| **falsifiable, probe stands as a program** | **1 of 38** | this file — a ratchet UP |
| **falsifiable, probe MISSING** | **37 of 38** | *nobody, until this file* |

**The third row is the whole reason this document is not two ratchets.** A ratchet on the
unfalsifiable count does not fall when nobody writes a probe; a ratchet on the probe count
only rises when somebody does. **The state the tree is actually in is the one neither of them
can see** — and it is 37 of 38.

*A count cannot watch it either*, and for exactly the reason `A = 19` failed: a count grows
with the corpus, so writing one more example program makes the number worse without making the
tree worse. **So the guarded figure is a PROPORTION.**

---

## `A_p`, defined

> **`A_p` = falsifiable assumptions whose named probe stands as a program in `sonden/`,
> divided by falsifiable assumptions.**

Both halves come out of the same scan, and both are named here rather than left to a reader:

* **The corpus is `beispiele/` plus the entries the CHECKER generates.** That is exactly what
  `gabbro annahmen beispiele/*.gab` prints — the assumption set Gabbro carries outward, and
  the same measurand `A` had. It is deliberately narrower than
  `pruefe-unfalsifizierbar.py`'s corpus, which reads every non-poison `.gab` in the tree: a
  `falsifier` in `messung/proben/` is an input written to make the checker say something, and
  counting it here would inflate the denominator with debt nobody carries. **The wider figure
  is not dropped, it is reported beside the quota** — see *What stands outside* below.
* **A falsifiable assumption** is one whose declaration carries `falsifier <probe>`. The
  grammar admits `assume`, `axiom` and `retires`, and the third one names its assumption
  after the function (`manifest.rs::stilllegungsannahmen`), which is why row 25 below has a
  name no `.gab` contains.
* **"Stands as a program"** means `sonden/<probe>.c` exists. Nothing about whether it runs,
  and nothing about whether it runs green — `sonden/README.md` fixes the contract, and return
  code **77** (*not runnable here*) is a full member of it.

```bash
./instrumente/pruefe-sondendeckung.py
# ==   1 of 38 falsifiable assumptions carry a probe that stands as a program
```

**And the denominator is not free either.** Three ways exist to keep `A_p` from falling when
an assumption is added, and only one of them is work:

1. **write the probe** — the quota holds;
2. **write `unfalsifiable`** — the assumption leaves this denominator and enters
   `dokumente/UNFALSIFIZIERBAR.md`'s, whose ADMITTED count **may not rise**. The exit is
   latched, and it costs a row under a criterion that must already be written down;
3. **do not declare the machine dependency at all** — and *nothing here catches that*. No
   guardian over a register can see a sentence nobody wrote. It is named because the honest
   limit of this file is that it measures declared assumptions, not real ones.

## The floor — and it is the whole point

**A proportion-ratchet alone forbids regression and demands nothing.** At 1 of 38 a ratchet
booked at today's level passes forever while nothing is written. So `A_p` carries a **floor**
as well as a ratchet, and the floor is chosen so the tree **fails it today**.

> ### `A_p ≥ 1/8`
>
> **Today `A_p = 1 / 38 = 0.026`. The floor is 0.125. The tree misses it by a factor of
> 4.75, and `pruefe-sondendeckung.py` is RED for exactly that reason.**

### Where `1/8` comes from — it is not a round number

`sonden/README.md` and `messung/RACE.md` §5.4 already carry the classification this floor
rests on: for each named probe, **what it would need in order to exist**. Four classes, and
they are read from there rather than invented here:

| | what the probe would need | of 38 |
|---|---|---:|
| **`P1`** | **ring 0** — a control register, a page table, an MSR, an `in`/`out` | 14 |
| **`P2`** | **a device** — VT-d, virtio, a 16550, a timer, a counter | 15 |
| **`P3`** | **a mechanism the generator does not emit** — a grace period, a reader that fetches, a source that ends | 4 |
| **`P4`** | **nothing — it runs in userland on the bench this folder already has** | **5** |

*The classification is an ESTIMATE per name and not a measurement; `sonden/README.md` says so
about its own table, and that caveat travels with these rows.* What is not an estimate is the
consequence:

> **`P4` is the work that needs no device, no privilege and no decision by the owner.** Five
> rows stand in it, **one of them has a program**, and the other four are the entire set of
> probes this folder could write today with a C compiler.
>
> `1 + 4 = 5` of 38 is **0.1316**. The largest unit fraction below it is **`1/8` = 0.125**;
> `1/7` = 0.143 is already out of reach. **So `1/8` is the tightest simple bound that the work
> which is actually possible reaches — and the tree is nowhere near it.**

### What reaching the floor costs

**Four probes.** Each is a userland C program under `sonden/`, each needs a sensitivity arm
(`sonden/README.md`: *„Wer keine Empfindlichkeitsprobe hat, hat keine Sonde"*), and each has
to be entered in `manifest::SONDEN_MIT_PROGRAMM` or the checker keeps striking its name:

| probe | assumption | what it does |
|---|---|---|
| `sonde_mxcsr_rne` | `gleitkomma_rundungsmodus_ist_rne` | read MXCSR, fall if the rounding mode is not round-to-nearest-even |
| `sonde_keine_ueberbreite` | `gleitkomma_x86_rechnet_mit_sse2` | evaluate an expression whose result differs between 64 and 80 bits |
| `sonde_tsc` | `rdtsc` | read the counter twice and fall if it does not advance; **77** if `CR4.TSD` forbids it |
| `sonde_rdtscp` | `rdtscp` | `CPUID` leaf `0x8000'0001`, then the instruction; **77** where the feature is absent |

With all four: **5 of 38 = 0.132 ≥ 0.125.** The floor is met and not exceeded — *by design,
because a floor with slack in it is a floor nobody has to think about again.*

**And one line is free but does not help.** `release_stellt_sichtbarkeit_her` is booked
`unfalsifiable` under a reason `dokumente/UNFALSIFIZIERBAR.md` REFUSES (`R1`), and the program
that would refute it already stands in `sonden/`. Rebooking it to
`falsifier sonde_release_sichtbarkeit` costs no probe, closes the orphan below, and moves
`A_p` to **2 of 39 = 0.051** — still less than half the floor. *It is the right change and it
is not the price.*

### What this floor is NOT

**It is not a target, and it is not enough.** It is the first bound the tree fails, and it is
derived from the only work that requires no new hardware, no kernel and no decision. The 29
rows in `P1` and `P2` stay exactly where they are: a probe for `write_cr3` needs ring 0, and
whether this project ever gets a bench with ring 0 is a question about apparatus that no
guardian can force. **`1/8` says what can be demanded today. It says nothing about what would
be enough.**

*The floor may be RAISED and may not be lowered.* A run that fails
[`the reachability tooth`](#the-teeth) — the floor no longer reachable even with every `P4`
probe written — is a finding about the corpus growing faster than the bench, and the answer to
it is a decision about apparatus, **not a smaller number here.**

## The other direction — a program nobody names

**A built program that no `falsifier` references is the same build type as a name without a
program, just reversed.** Both are a connection with one end missing, and both are held
here.

```bash
ls sonden/*.c | wc -l                                    # 2
```

`sonde_release_sichtbarkeit.c` exists, runs, and carries a positive control that fell 3 079
times in 1,5 million rounds. **No line in any `.gab` names it.** `sonden/README.md` said so on
the day it was built — *„Bis die Zeile in `beispiele/` steht, ist sie eine Sonde ohne
Verpflichtung"* — and `N024` (*a probe belongs to exactly ONE obligation*) has nothing to hold
it to.

| | program | why no `falsifier` names it | since |
|---:|---|---|---|
| 1 | `sonde_release_sichtbarkeit` | `release_stellt_sichtbarkeit_her` is booked `unfalsifiable`, so the grammar has no slot for the name. The reason is REFUSED under `R1` in `dokumente/UNFALSIFIZIERBAR.md`; the repair is one line in `beispiele/06-annahmen.gab` | 2026-08-21 |

**1 orphan program is booked. The mark may fall and not rise.** Unlike the quota this one is a
plain count, because it is not a share of anything: every program in `sonden/` should be bound
to an obligation, and the target is zero.

table, and an assumption cannot be added without a row appearing.* The probe name must be the
one the corpus declares; the class must be one this document defines; the program column must
agree with what stands in `sonden/`.

*No line numbers.* Over 38 rows in 14 files a line column produces a stream of drift

## What stands outside

`falsifier` clauses live in the tree beyond `beispiele/`, and they are counted here so the
narrower denominator above cannot hide them:

```bash
grep -rhoI "falsifier [a-zA-Z_0-9]*" --include=*.gab . --exclude-dir=gift \
  | sed 's/falsifier //' | sort -u | wc -l
# 48
```

**48 distinct probe names in the whole non-poison corpus, 37 of them in the register above.**
The other **13** stand in `messung/fragmente/` (a frozen Caprock excerpt), `messung/proben/`
(inputs written to make the checker speak) and `messung/treiber/`. *None of them has a
program either*, and the count is booked so it cannot grow in silence.

## The teeth

Ten, and each one can come out wrong — `pruefe-sondendeckung.py` runs **19 speech tests**, at
least one per tooth and both directions where a tooth has two, and the last of them is the
control that keeps the other eighteen from passing over a guardian that always says no.

| | tooth | what it forbids |
|---:|---|---|
| 0 | the subject exists | a green verdict over a missing document or an empty `sonden/` (`W17`) |
| 1 | rows == the corpus, both ways | an assumption added without a row; a row kept after its clause is gone |
| 2 | no assumption twice in the register | a doubled row — *set equality does not see it, and it is still counted where tooth 7 decides* |
| 3 | every row names the probe the corpus declares | a register that drifts from the source it describes |
| 4 | every row's class is defined here | a class invented at the moment of classification |
| 5 | the program column agrees with `sonden/` | a row that claims a program that is not there, or hides one that is |
| 6 | **`A_p` ratchet** | the quota falling — *an assumption added without its probe* |
| 7 | **`A_p` floor `≥ 1/8`** | **fails today.** A quota that is allowed to stay where it is |
| 8 | the floor stays reachable | a corpus that grows past what a bench without ring 0 can ever cover |
| 9 | orphan programs `≤ 1` | a second program bound to no obligation |
| 10 | `SONDEN_MIT_PROGRAMM` == `sonden/*.c` | **coverage claimed in the checker with no program behind it** |

Tooth 10 is the one that makes the rest load-bearing. `manifest::gedeckt` decides from a
constant list whether a probe name stands or is struck; without this tooth, adding a string to
that list would raise `A_p` **with no program written at all** — the same move as writing
`unfalsifiable`, one layer down and invisible from here.

**What no tooth does.** Whether a probe would actually refute its assumption is nobody's
script: `pruefe-sonden.sh` says so about itself (*„Was hier gemessen wird, ist DASS eine
laeuft, nicht WORUEBER"*), and the class of a row is an estimate a reader may dispute. What is
excluded is the pair of things a script can exclude: **that the quota falls unseen, and that a
row stands under a class nobody wrote down.**
