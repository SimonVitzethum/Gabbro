## 1. `H = 0` — does not hold. The criterion was calibrated on three cases it gets wrong.

### 1.1 What the code actually does

`instrumente/zaehle-pflichten.py:383-410`. The whole criterion is two lines:

```python
    for name, quelle in offen:
        n = _pruefe_fehler(quelle)
        fehlerzahl[name] = n
        if n == 0 or locker:
            klempnerei.append(name)
        else:
            notation.append(name)

`_pruefe_fehler` (`:352-380`) runs `gabbro pruefe` over the **whole file** and returns the
integer out of `N items, M errors, K hints`. `H` is then `len(klempnerei)` plus the anchored

asks *why* the checker refuses, *where* in the file it refuses, or whether the refusal has
anything to do with the lowering obligation the row is about. The docstring above it states a
different criterion — *"a plumbing obligation is one that Gabbro's own machinery can discharge

that criterion has at least three states where the implementation has two:

| state | stated criterion | implementation |

| checker accepts, emitter arm missing | plumbing | plumbing |
| the text uses a construct the language does not have | notation | notation |
| **the FRAGMENT is wrong, in notation Gabbro already has** | **neither — the input is broken** | **notation** |

The third state is where `F03` is, and it is where `F01`, `F05` and `F09` were two days ago.

## 2. `L = 2` against `<= 4` — the count holds, the gate does not exist

### 2.1 What `carried` means in the code

```

--   of those CARRIED unproved (the compiler rests on them): 2

`crates/gabbro-check/src/schablonen.rs:1033-1038`:

```rust
pub fn lebend_ungedeckt() -> usize {
    SCHABLONEN
        .iter()
        .filter(|s| s.stand == Stand::Getragen)
        .count()
}
```

Population: the const array `SCHABLONEN` in the same file. **21 entries — 10 `Bewiesen`,
2 `Getragen`, 9 `Entworfen`** (`grep -oE "stand: Stand::[A-Za-z]+" | sort | uniq -c`). The
arithmetic is right: `L = 2`.

**`Getragen` is a hand-typed enum literal.** There is no derivation from any use site
anywhere — no consumer of `SCHABLONEN` compares `stand` against `emit.rs`. So the parenthesis
*"(the compiler rests on them)"* is an editorial gloss on an annotation, not a measurement.

### 2.2 The annotation and the tree disagree, in the direction that keeps `L` low

`Entworfen` is documented (`schablonen.rs:43-51`) as *"In der Spezifikation benannt, **kein
Erzeugercode**"*. Two entries carry it while the emitter has an arm for the construct they
name:

* **`gruppe.sperrabdruck`** (`schablonen.rs:829`, `stand: Stand::Entworfen` at `:876`, with
  the comment *"Stand bleibt ENTWORFEN: es gibt keine Gruppen-`ops`."*). But
  `zeugnis.rs:271-275` books the `locks` construct as `Traegt::Schablone("gruppe.sperrabdruck")`,
  and `Traegt::Schablone` is documented at `zeugnis.rs:63-65` as *"**Erzeugt.** Der Erzeuger
  stellt Code her, den niemand geschrieben hat"*. The tool prints the contradiction:

  ```bash
  ./target/debug/gabbro zeugnis beispiele/05-nebenlaeufigkeit.gab
  ```
  ```
  B  THE TEMPLATES -- what the GENERATOR produces, which nobody wrote
       gruppe.sperrabdruck      designed   2x  locks
  ```

  *A template listed under "what the generator produces" whose state says the generator
  produces nothing.* Nothing in the tree asserts `Traegt::Schablone(x) ⇒ x.stand != Entworfen`.

* **`walk.mappings`** (`schablonen.rs:544`, `Entworfen` at `:555`). Its `konstrukt` is
  *"walk … levels / mappings of"* — **two constructs under one entry, and the emitter treats
  them oppositely.** `emit.rs:2365` dispatches `ItemArt::Walk(w) => walk_(w, …)` into a full
  generator arm (`fn walk_`, `:10479`, emitting a typedef, two predicates and a descent
  loop); `emit.rs:8666` refuses `mappings of` with `C001`. So half of the named construct has
  generator code and half is an open finding — and `Stand` is **one field with three mutually
  exclusive values**, which cannot say that. This one is not a wrong annotation; it is an
  annotation that has no true value available.

Booked honestly, the first of these is either `Getragen` — which makes `L` **3** — or
`zeugnis.rs:273` is pointing the `locks` construct at the wrong template. **Which of the two
is wrong is a decision, and nothing in the tree forces it to be made:** no test asserts
`Traegt::Schablone(x) ⇒ x.stand != Entworfen`, and `gabbro zeugnis` prints the contradiction
on every unit with a `locks` statement.

## 5. The meta-question: do the four together mean *100 % plumbing coverage*?

**No, and three of the four have drifted from the thing they proxy.**

`K100`'s headline is a percentage over the obligations of `dokumente/PFLICHTEN.md`. Its own
opening (`PLAN.md:1234`) states the base: *"173 Klempnereipflichten über den zehn Fragmenten,
137 getragen, 36 hängend"*. Today `zaehle-pflichten.py --spalten` gives `173 K` and
`--haengend` gives `H = 0`, so the ratio is `173/173`. Four things break the inference:

1. **No gate computes the ratio.** `H` is a raw count of the hanging side. The denominator is
   read out of a hand-written third column that the same script counts in a different mode —
   and the two modes disagree about `F03` (§1.7). The percentage in the headline is derived
   nowhere.

2. **The denominator is ten fragments chosen for difficulty**, and the tool says so in its own
   closing lines: *"Die zehn Fragmente sind nach ihrer SCHWIERIGKEIT gewaehlt; `H = 0` ueber
   ihnen bliebe Falle 80, solange kein Korpus daneben steht, den beim Bauen niemand angesehen
   hat."* Gate three was supposed to be that corpus, and §3 says it is not.

3. **What counts as plumbing is set by the checker's current strictness**, not by the
   language (§1.1–§1.4). Under the criterion adopted on 2026-09-04, the same four obligations
   that the tree measured as `H = 4` on 2026-09-03 measure as `H = 0`, and three of them were
   then discharged as plumbing. *A coverage figure whose numerator moves when the checker gets
   stricter is not a coverage figure.*

4. **`L` was the guard against moving the debt instead of discharging it** — `PLAN.md:1269`:
   *"Ein Plan, der nur `H` verfolgt, erreicht 100 % und ist danach schlechter dran."* That
   guard is a hand-typed enum field — one entry of which the certificate table contradicts and
   one of which has no true value available — a bound no machine checks, and a bar set at the
   day's value (§2). It is not currently able to price a move from `H` into the generator
   surface.

The fourth gate, `A_p`, is the healthiest of the four — and it is a gate about the **hardware
assumption layer**, not about plumbing coverage. Its presence in the `K100` table is a
different measurement standing in a table named after a percentage.

> **The four gates are three proxies that grew apart from their headline and one measurement
> from a neighbouring question.** The conjunction does not entail 100 % plumbing coverage. It
> entails: over ten fragments chosen for difficulty, nine lower and run; the tenth is refused
> by the checker for eighteen reasons of which fifteen are repairable in the file; the
> generator's live unproved surface is two entries by an annotation nobody derives; the second
> corpus caused two of the rules it is measured against; and one probe in thirty-eight exists
> as a program.

*That sentence is a good deal weaker than the headline, and every clause in it is a run.*
