The most frequent single messages: `function X is not impl` 12 (`spec`, `const`, `raw`,

## 3. The mechanism (what "Lean green" now means per program)

* `grammatik/Grammatik/Zertifikat/` holds ONE GENERATED file per exported, accepted program:
  the output of `gabbro obligations --g <program>` byte for byte (the exported `Einheit`, the
  complete member lists, `gCheck : akzeptiert_pruefer.akzeptiert gE gFs gLs gCs = true := by
  decide`, and `gP_gabbro`, the goal theorem on the program with the user's duty as the
  hypothesis). 104 and 108 keep their existing `GenOblig104/108.lean`.
* `grammatik/Grammatik/Zertifikate.lean` imports every certificate; `Grammatik.lean` imports
  it, so `./lean-bau` elaborates every one and decides every checker premise.
* `grammatik/Grammatik/Zertifikat/REGISTER.txt` is THE ONE LIST: every accepted program under
  `beispiele/`, either `CERTIFIED` (module, chain state, hand-term note) or `UNCERTIFIED` (the
  exporter's code and message).
* The cargo test `tests/zertifikate.rs` recomputes all three from the tree and fails when any
  byte differs: a new accepted program without a certificate or a registry row, a stale
  certificate, a registry row for a program that now exports, an umbrella that misses a module.
  `GABBRO_ZERTIFIKATE=schreiben cargo test --test zertifikate` rewrites them.
