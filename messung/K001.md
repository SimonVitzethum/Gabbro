# `kosten.summation` — das Korrektheitsargument, und was es beim Schreiben gefunden hat

*Geschrieben am 2026-08-24. Der erste Satz des Passregisters, der `ARGUED` erreicht.*

> **Das Ergebnis zuerst, weil es die Übung rechtfertigt:** beim Durchrechnen der
> Fallunterscheidung fiel eine **Unterzählung** auf. Zwei Rümpfe mit *identischer Bedeutung*
> rechneten **2** und **6** — und der mit der 2 ging mit `costs <= 2 ops` und **null Fehlern**
> durch. `K001` ist eine obere Schranke; eine Unterzählung ist die einzige Fehlerrichtung, die
> zählt.
>
> **Kein Test fiel. Keine Mutation griff. Es fiel auf, weil jemand den Satz hinschreiben
> musste.**

---

## 1. Was zu zeigen ist

**Das Modell** (`SPRACHE.md` §7): eine Ausführung kostet die Zahl der ausgeführten
**Primitiven**, und es gibt vier — Zuweisung, Rechenoperation, Laden, Speichern.

Für einen Rumpf `b` sei

```
  K(b, r)   die Zahl der Primitiven, die der Durchlauf r durch b ausführt
  Ĉ(b)      die Zahl, die `kosten.rs::block` statisch ausrechnet
  E         die Zusage aus `costs <= E ops`
```

**Der Satz** zerfällt in zwei Hälften, und sie sind unabhängig:

| | |
|---|---|
| **L1 · Überdeckung** | `Ĉ(b) ≥ K(b, r)` für **jeden** Durchlauf `r` |
| **L2 · Vergleich** | wenn `Ĉ(b) ≤ E(0)`, dann `Ĉ(b) ≤ E(σ)` für jede zulässige Belegung `σ` |

Aus beiden folgt: **jeder Durchlauf eines Rumpfs, der `K001` passiert, führt höchstens `E(σ)`
Primitiven aus.** *Das ist der Satz, und mehr behauptet er nicht.*

---

## 2. L2 zuerst, weil sie kurz ist

Der Pass liest `E` als `Term { fest: c, glieder: {s₁: a₁, …} }` — eine Konstante plus
**Vielfache nichtnegativer Größen**, und verglichen wird bei `σ = 0`.

**Argument.** Alle `aᵢ ≥ 0` (geprüft, `K005`) und alle `sᵢ ≥ 0` (Prämisse, geprüft). Dann ist
`E(σ) = c + Σ aᵢ·sᵢ(σ) ≥ c = E(0)` für jedes zulässige `σ`. Aus `Ĉ(b) ≤ E(0)` folgt also
`Ĉ(b) ≤ E(σ)`. ∎

**Die Prämisse ist nicht kosmetisch.** Ohne Nichtnegativität gäbe es keine kleinste Belegung,
und `costs <= 40 * n` wäre bei `n = -1` negativ. *Deshalb ist `K005` kein Komfort, sondern die
Voraussetzung, unter der L2 überhaupt gilt.*

---

## 3. L1 — strukturelle Induktion, Fall für Fall

Zu zeigen: `Ĉ` überschätzt nie. Induktion über den Aufbau von Anweisungen und Ausdrücken.

### Ausdrücke

| Form | `Ĉ` | Argument |
|---|---|---|
| zur Übersetzungszeit konstant | **0** | **Prämisse über den ERZEUGER**, keine über den Pass: für eine Konstante wird keine Primitive emittiert. *Siehe §5 — das ist die schwächste Stelle des ganzen Arguments* |
| Zahl, `true`, `false`, `&f`, Grundwert, `result` | **0** | dieselbe Prämisse |
| Ort `x.a[i].b` | **1 + #Indizes** | ein Laden, plus je Indexrechnung eine |
| unär `∘e` | `1 + Ĉ(e)` | eine Rechenoperation, dann induktiv |
| binär `a ∘ b` | `1 + Ĉ(a) + Ĉ(b)` | **Überschätzung bei Kurzschluss**: wertet `&&` die rechte Seite nicht aus, kostet der Durchlauf weniger. *In die richtige Richtung* |
| Ruf | die **deklarierten** Kosten | siehe §4 |

### Anweisungen

**Folge.** `Ĉ(s₁; …; sₙ) = Σ Ĉ(sᵢ)`. Ein Durchlauf führt sie hintereinander aus; mit der
Induktionsvoraussetzung gilt `Σ K(sᵢ, r) ≤ Σ Ĉ(sᵢ)`. ∎

**Der Sonderfall in `block`.** Steht `if c { … return … }` ohne `else` und **verlässt der Zweig
immer**, so gibt es genau zwei Wege: *durch* den Zweig, oder *daran vorbei und weiter*. `Ĉ` nimmt
das Maximum der beiden statt ihrer Summe.

> *Ohne diese Regel zahlt jeder frühe Rückstieg zweimal, und die Zahl misst einen Weg, den kein
> Durchlauf nimmt.* **Sie ist eine Verschärfung, keine Lockerung** — sie darf, weil `endet_immer`
> garantiert, dass die zwei Wege sich ausschließen.

**Fallunterscheidung — und hier saß der Fehler.**

`WennStmt::zweige` ist **flach**: ein `else if` ist ein weiterer Eintrag, keine geschachtelte
Anweisung. Damit gilt für einen Durchlauf, der Zweig `i` nimmt:

```
   er hat die Bedingungen 0 … i AUSGEWERTET, und den Rumpf i ausgeführt
```

und für einen, der `sonst` erreicht: **alle** Bedingungen.

**Bis zum 2026-08-24 rechnete der Pass** `max over i (Ĉ(bedᵢ) + Ĉ(rumpfᵢ))` — nur die *eigene*
Bedingung je Zweig, und für `sonst` **gar keine**. Gemessen:

```gabbro
impl fn kette(a, b, c) -> u32 costs <= 2 ops {         impl fn folge(a, b, c) -> u32 costs <= 2 ops {
    if a > 5 { return 1; }                                 if a > 5 { return 1; }
    else if b > 5 { return 2; }                            if b > 5 { return 2; }
    else if c > 5 { return 3; }                            if c > 5 { return 3; }
    else { return 4; }                                     return 4;
}                                                      }
```

```
-- Stelle   gerechnet   zugesagt   Luft
kette       2           2          0        <- 0 Fehler
folge       6           2          -4       <- K001 faellt
```

> **Zwei Rümpfe gleicher Bedeutung, zwei Zahlen — und die kleinere war die falsche.** Die
> sequentielle Form war immer richtig: `block` läuft sie Anweisung für Anweisung ab und
> summiert. **Nur die flachgeklopfte Kette verlor ihren Präfix.**

**Die Regel, korrigiert:** sei `Pᵢ = Σ_{j≤i} Ĉ(bedⱼ)` der Präfix der Bedingungen. Dann

```
   Ĉ(if …) = max(  max over i ( Pᵢ + Ĉ(rumpfᵢ) ),  P_{n-1} + Ĉ(sonst)  )
```

**Argument.** Jeder Durchlauf nimmt genau einen Zweig `i` oder `sonst`. Nimmt er Zweig `i`,
kostet er `Σ_{j≤i} K(bedⱼ) + K(rumpfᵢ) ≤ Pᵢ + Ĉ(rumpfᵢ)` nach Induktionsvoraussetzung, und das
ist ein Argument des Maximums. Erreicht er `sonst`, kostet er `P_{n-1} + K(sonst)`, ebenso. ∎

**Und ohne `sonst` braucht der Durchfallweg keinen eigenen Zweig:** er kostet `P_{n-1}`, und der
*letzte* Zweig zählt bereits `P_{n-1} + Ĉ(rumpf_{n-1}) ≥ P_{n-1}`.

**`match`.** `Ĉ(gegenstand) + max over Zweige Ĉ(rumpf)`. Hier ist die flache Liste kein Problem:
ein `match` wertet **einen** Gegenstand aus und springt; es gibt keine Kette von Bedingungen.
*Der Unterschied zwischen `match` und `else if` ist genau der, an dem der Fehler hing.*

**Schleifen.**

| Form | `Ĉ` | Argument |
|---|---|---|
| `traverse … over D` | `Ĉ(rumpf) × |D|` | jeder Durchlauf betritt den Rumpf höchstens `|D|`-mal. **Und `|D|` ist der schwache Punkt — siehe `kosten.domaenenschranke`, §6** |
| `retry … bounded N` | `N` | die Schranke IST die Zusage; `K006` hält sie gegen den Rumpf |
| `forever` | `Unbekannt` | eine nicht endende Schleife hat keine Gesamtkosten. *Der Pass sagt es, statt eine Zahl zu erfinden* |

**Überlauf.** `plus` und `mal` rechnen `checked_*`; ein Überlauf wird `Unbekannt`, nicht eine
kleine Zahl. **Das ist eine Voraussetzung von L1**, keine Feinheit: bis zum 2026-08-19 ergaben
vier geschachtelte `traverse` über `count 4294967295` ein **negatives** Produkt, und
`costs <= 4 ops` galt für einen Rumpf mit 10³⁸ Schritten, mit null Meldungen.

## 4. Der Ruf — und warum der Satz hier eine Annahme wird

**Ein Ruf zählt die DEKLARIERTEN Kosten des Gerufenen, nie seine gerechneten.**

Für einen azyklischen Aufrufgraphen trägt das: der Gerufene hat seinerseits `K001` passiert,
also ist seine Deklaration eine obere Schranke seiner Durchläufe — Induktion über die
Topologie. ∎

**Am Zyklus bricht die Induktion**, und der Pass sagt es: *„`costs` an einer rekursiven
Funktion ist eine **Annahme**, kein Ergebnis."* Mit `decreases` ist `costs` die Zusage **eines
Durchgangs**, und die Tiefe steht im Maß — *ohne diese Lesart fiel `K001` an jeder korrekten
rekursiven Funktion, und das war der Grund, warum niemand eine schrieb.*

**Der indirekte Ruf** zählt, was der **Zeigertyp** zusagt (`N035` erzwingt die Zusage,
`M128` hält den Rumpf dagegen: *weniger versprechen als der Platz ist erlaubt, mehr nicht*).
Beide Fehlzweige sind `Unbekannt` **mit Grund**, nie `Zahl(0)` — *eine Kostenzahl, die nicht
feststeht, ist nicht null.*

---

## 5. Wo das Argument am schwächsten ist — und es ist nicht die Rekursion

**`Ĉ(konstanter Ausdruck) = 0` ist eine Aussage über den ERZEUGER, und dieser Pass prüft sie
nicht.**

Der Satz *„was zur Übersetzungszeit feststeht, kostet zur Laufzeit nichts"* ist genau dann
wahr, wenn `emit.rs` für einen konstant auswertbaren Ausdruck keine Primitive ausgibt.
**Nichts im Kostenpass hält das nach**, und `emit.rs` trägt **eine** Absagekennung und
**null** Sätze.

> **Damit hängt L1 an einer Aussage über 6 976 Zeilen, die niemand aufgeschrieben hat.** Das
> ist derselbe Ort, an dem der `mappings of`-Fehler gefunden wurde: *der Erzeuger lief hinein.*

*Das ist kein Grund, den Satz nicht zu schreiben — es ist der Ertrag des Schreibens.* Er steht
jetzt als benannte Prämisse da statt als stillschweigende.

---

## 6. Die andere Hälfte, und sie bleibt `CONJECTURED`

`kosten.domaenenschranke` (`K003`) sagt: `|D|` ist die **Mächtigkeit** der Domäne, wie sie aus
der Deklaration folgt.

**Der Pass LIEST die Zahl; nichts prüft, dass die gelesene Zahl die Mächtigkeit IST.** Für
`mappings of` las er `Ebenen × Knotenlänge = 2 048`, wo die Domäne die **Blattmenge** ist:
`Knotenlänge ^ Ebenen = 512⁴ = 68 719 476 736`. **Sieben Größenordnungen, drei Tage getragen** —
und gefunden, weil der Erzeuger hineinlief, nicht weil ein Test fiel.

**Er ist korrigiert. Der Satz bleibt trotzdem `CONJECTURED`**, und der Grund ist strukturell:
`K003` hat zwei Giftproben, und die messen, dass eine **fehlende** Schranke abgelehnt wird —
nicht, dass eine **vorhandene** stimmt. *Genau in diesem Unterschied hat der Fehler drei Tage
gelebt, und jede andere Domänenschranke des Passes hat dieselbe Bauart und dieselbe Prüfung:
keine.*

> **Was ein Argument hier brauchte, ist eine Aussage je Domänenform** — Tabelle, `queue`,
> `mappings of` —, dass die gelesene Deklaration die Trägermenge des Durchlaufs beschreibt. Das
> ist drei kleine Sätze, und keiner davon steht.

---

## 7. Was `ARGUED` an diesem Satz heißt, und was nicht

| | |
|---|---|
| **`kosten.summation`** | **`ARGUED`** — L1 und L2 stehen oben, Fall für Fall, mit ihren Prämissen |
| **`kosten.domaenenschranke`** | **`measured`** seit 2026-08-31 — alle fünf Domänen tragen Probe und Mutation. *`measured` misst die UMSETZUNG, nicht die Regel: die drei Domänensätze aus §6 fehlen weiter, und dafür steht `PROVED` leer.* |

**Und was `ARGUED` nicht ist:** ein Beweis. Nichts oben ist maschinengeprüft. Die Induktion
setzt voraus, dass die Fallliste in §3 **vollständig** ist — also dass ich keine
`StmtArt`-Variante übersehen habe —, und dafür gibt es kein Werkzeug, nur mein Nachsehen.

> **Der Ertrag steht in §3 und nicht in der Spalte:** eine Unterzählung um Faktor 3, gefunden
> in der ersten Stunde des ersten Satzes, gegen die 286 Mutationen und 255 Giftproben blind
> waren. *Sie waren es nicht aus Nachlässigkeit — es gab keine Probe, weil niemand die Frage
> gestellt hatte.*

**Behoben, mit Probe und Anker:** `beispiele/gift/256-zweigkette-praefix.gab` fällt an `K001`
und täte es vor der Korrektur nicht; `zweigkette-verliert-praefix` in `mutiere-pruefer.py`
stellt den alten Zustand her und wird gefangen.
